# **Rolling Sphere and Statistical Analyses**

## **Overview**
This repository contains **R scripts and datasets** required for reproducing the rolling sphere analysis and most statistical analyses from:

> **Costa RM, Acosta-Alvarez L, Curtis K, Zarbock K, Kelleher J, et al.**  https://github.com/RodrigoMamedeCosta/flu-evolution/blob/main/README.md
> *Host genotype and sex shape influenza evolution and defective viral genomes* (2025).  

## **Contents**

- `Figures and Tables` -  Main and supplemental figures (SVG format) and tables.

- `Rolling sphere` – Script for the rolling sphere model used to detect positive selection, along with the required data (in the format of
   filtered ancestral and derived reads and PDB-derived distance matrices).

- `Statistical analysis scripts and data` – Contains data and scripts for all statistical analyses, and the required data files. Scripts are in Rmd format (may require rmarkdown and/or knitr).

- `Additional data` - SRA submission details and  modified PDBs for chimera/chimerax, used to generate the visualizations.

## **Installation & Requirements**
Ensure you have **R 4.0+** installed. Required packages are included in scripts.
